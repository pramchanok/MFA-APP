# รวมรหัสที่มีอยู่ในมือถือไว้บนคอม

## เปิดแอป

เปิด MFA Desktop 0.5.0 หลัง build หรือติดตั้งจาก artifacts ของ manual GitHub Actions ตั้งรหัสผ่านหลักอย่างน้อย 6 ตัวอักษร หากมีคลังจากรุ่นเดิมให้ใช้รหัสผ่านเดิม ข้อมูลยังอยู่ใน app data identifier เดิม ไม่ต้องสร้างคลังใหม่ การนำเข้าจาก Google เพิ่มรวมกับข้อมูลเดิม ส่วนเมนูนำเข้าไฟล์สำรองเป็นการแทนที่ทั้งคลังและเป็นคนละขั้นตอน

## Google Authenticator

รุ่น 0.4.1 รองรับข้อมูลส่งออกเวอร์ชัน 1 และ 2 แก้กรณีอ่านรูป QR ได้ แต่รุ่นก่อนแจ้งว่าข้อมูลเสียหายเพราะรับเฉพาะเวอร์ชัน 1 ดู [ผลตรวจด้วยรูปจริงและข้อมูลจำลอง](verification-google-v2-2026-10-09.md)

1. เปิด Google Authenticator บนมือถือ เลือก **โอนบัญชี → ส่งออกบัญชี** (Transfer accounts / Export accounts) แล้วเลือกบัญชี
2. เปิด QR ชุดส่งออกไว้บนหน้าจอมือถือ ไม่จำเป็นต้องบันทึกเป็นภาพ
3. ใน MFA Desktop กด **เพิ่ม / นำเข้าบัญชี → สแกนด้วยกล้อง** แล้วส่อง QR บนมือถือ หรือกด **เลือกรูป QR** เพื่อเลือกภาพที่มีอยู่ แอปตรวจชนิด QR เอง หากมีหลาย QR ให้สแกนหรือเลือกภาพเพิ่มให้ครบชุดเดียวกันก่อนบันทึก
4. ตรวจชื่อบัญชีและเลือกเฉพาะที่ต้องการ ระบบไม่แสดงคีย์ลับในรายการ ตรวจซ้ำด้วยชื่อบริการและบัญชีที่ตรงกันทุกตัวอักษร รายการ HOTP/อัลกอริทึมที่ไม่รองรับจะแสดงเหตุผลและเลือกไม่ได้
5. กด **นำเข้า N บัญชี** แล้วตรวจว่ารหัสของบัญชีเดียวกันตรงกับมือถือในช่วงเวลาเดียวกัน รหัสใกล้หมดอายุอาจเปลี่ยนระหว่างดูสองหน้าจอ ให้ตั้งเวลาเครื่องอัตโนมัติ
6. สำรองคลังที่เข้ารหัส และลบรูป QR ส่งออกเมื่อใช้งานเสร็จ รูป QR มีคีย์ลับ อย่าอัปโหลดลงแชทหรือเว็บไซต์ถอด QR

เป็นการคัดลอกคีย์เพื่อนำมาสร้างรหัสในเครื่อง ไม่ล็อกอิน Google และไม่ซิงค์การเพิ่ม/ลบบัญชีในมือถือภายหลัง ไม่ต้องเปลี่ยนการตั้งค่า 2FA ของแต่ละเว็บไซต์เพื่อใช้วิธีนำเข้านี้

ตัวอ่าน migration ใช้รูปแบบ protobuf ที่มีการเผยแพร่โดยนักพัฒนา [schema อ้างอิง](https://github.com/qistoph/otp_export/blob/master/OtpMigration.proto) ไม่ใช่ API contract ที่ Google รับรอง รองรับ payload version 1 และ 2, TOTP SHA1/SHA256/SHA512, 6/8 หลัก รอบ 30 วินาที จำกัด 100 QR / 1,000 บัญชีต่อชุด หากรูปแบบส่งออกเปลี่ยน แอปจะต้องอัปเดตตัวอ่านก่อนใช้งาน

ดู [วิธีส่งออกของ Google](https://support.google.com/accounts/answer/1066447?hl=th)

## นำเข้าครั้งแรก แล้วซิงค์ระหว่างแอป MFA

หลังยืนยันนำเข้า รุ่น 0.3.5 แสดงจำนวนบัญชีที่เพิ่ม พร้อมปุ่ม **ดูรหัสที่นำเข้า** หรือ **ตั้งค่าซิงค์อุปกรณ์** การนำเข้าไม่สร้างคลังบนเซิร์ฟเวอร์เอง

- ยังไม่ได้ตั้งค่าซิงค์: ปุ่มตั้งค่าเปิดแท็บสร้างคลังใหม่ พร้อม URL Cloudflare ของโปรเจกต์ ใส่โทเคนสร้างคลังจากไฟล์ส่วนตัว `.tools/cloudflare-registration-token.txt` แล้วกด **สร้างคลังซิงค์** บัญชีทั้งหมดในเครื่องจะเข้าคิวส่งแบบเข้ารหัส
- ตั้งค่าซิงค์ไว้แล้ว: ใช้คลังเดิมและส่งบัญชีที่นำเข้าเพิ่ม แสดงสถานะกำลังส่ง รอส่ง หรือข้อผิดพลาดตามจริง กด **จัดการซิงค์ / จับคู่เครื่องอื่น** เพื่อดูสถานะและ QR จับคู่
- เครื่องถัดไป: ติดตั้งแอป MFA ของเรา เปิด **ซิงค์อุปกรณ์ → จับคู่กับเครื่องเดิม** แล้วนำ QR/รหัสจับคู่จากเครื่องแรกมาใช้ ไม่ต้องใส่โทเคนสร้างคลังซ้ำ

หลังจากนี้เพิ่มบัญชีผ่านแอป MFA เพื่อให้ซิงค์ถึงกัน หากเพิ่มใน Google Authenticator ต้องส่งออกและนำเข้าเพิ่มอีกครั้ง การซิงค์ทำงานขณะเปิดและปลดล็อกแอป รุ่นนี้ยังไม่มี APK/iPhone build ที่ตรวจบนโทรศัพท์จริง ดู [คู่มือ Cloudflare](cloudflare-sync.md) และ [ผลตรวจรุ่น 0.3.5](verification-google-sync-2026-10-09.md)

## Microsoft Authenticator

ยังไม่สามารถล็อกอิน Microsoft แล้วดึงรหัสหรือ cloud backup ของ Authenticator ทั้งหมดมาแสดงในแอปนี้ได้ Microsoft Graph Software OATH ส่ง `secretKey: null` เสมอ ไม่ใช่ API สำหรับดึงรหัส OTP จากแอปมือถือ

หากมี QR ตั้งค่า TOTP หรือคีย์เดิมของแต่ละบริการ สามารถเพิ่มผ่าน **เพิ่ม / นำเข้าบัญชี** แล้วสแกนด้วยกล้อง เลือกรูป วาง URI หรือกด **กรอกคีย์ลับแทน** ได้ หากไม่มี ต้องลงทะเบียน TOTP เพิ่ม/ใหม่จากหน้าความปลอดภัยของบริการนั้น โดยรักษาวิธีเข้าสู่ระบบสำรองไว้ บัญชีบริษัทต้องอนุญาต third-party authenticator

การกดอนุมัติ แจ้งเตือน จับคู่ตัวเลข และ passwordless ของ Microsoft ยังต้องใช้แอป Microsoft Authenticator เดิม ไม่รองรับโดยการนำเข้า TOTP

- [Microsoft backup/restore](https://support.microsoft.com/en-us/authenticator/back-up-your-accounts-in-microsoft-authenticator)
- [Graph Software OATH resource](https://learn.microsoft.com/en-us/graph/api/resources/softwareoathauthenticationmethod?view=graph-rest-1.0)
