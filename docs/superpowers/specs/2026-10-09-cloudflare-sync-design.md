# Cloudflare sync relay and ten-person capacity

User intent: use Workers + D1 Free for encrypted sync for roughly ten people, including Android/iOS and desktop, without an always-on Docker host. The existing API v1, pairing format and encryption remain compatible. Assume up to three devices per person; personal vaults remain isolated. No Google/Microsoft cloud access is introduced.

Implementation: add a dependency-free ES module Worker in `cloudflare/`, its own pinned Wrangler/Miniflare development toolchain, D1 migration and deployment guide. D1 primary reads authenticate each vault. Indexed incremental reads skip history when caught up. One JSON-to-view INSERT with triggers allocates sequences, enforces immutable record IDs and quotas, and updates counters; D1 batch atomically returns latest. Native rate bindings avoid D1 heartbeat/rate-counter writes. A bounded logical storage quota leaves room under D1's 500 MB Free database cap. Do not cache permissions or sync responses.

Client change: version 0.3.1 checks remote changes every 60 seconds after activity, 120 seconds while caught up, with error backoff capped at 300 seconds. Explicit refresh, foreground/online resume, and local mutations send immediately. Coalesce refresh requests during an in-flight sync; invalidate stale UI results on lock. Retain native encrypted outbox and idle locking. OTP generation remains local and updates each second.

Capacity target: 10 × 3 devices at 120/60-second polling means 21,600/43,200 scheduled GETs/day, excluding operations, retries, startup, manual traffic and abuse. Workers account-wide Free request quota is 100,000/day. Production CPU, latency, quota sharing and physical mobile tests are deployment gates, not conclusions from local tests. No global rate accounting guarantee or unlimited capacity is claimed.

Validation: real workerd + local D1 tests for strict schemas/auth boundaries, concurrent 10-user three-device writes, atomic conflict/quota rollback, duplicate retries, pagination/size caps, restart durability, indexed one-row idle reads without writes, native two-vault encrypted sync, React polling/lock/offline behavior, TypeScript/Vite build, Wrangler migration and deploy dry run. Build an unsigned Windows installer. No installed vault mutation, reset, repository push or automatic public deployment.

Delivery: Docker remains available as an alternative. Existing 0.3.0 clients must be updated for the polling budget; no encrypted database migration from Docker is implicit. After the user confirmed readiness and completed OAuth login, provision the new D1 database and public Worker, configure the owner secret without displaying it, and verify native encrypted sync over public HTTPS before reporting deployment success. This deployment extension is now verified in `docs/verification-cloudflare-2026-10-09.md`.
